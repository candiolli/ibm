# 🎵 Acervo de Músicas — Ministério de Louvor

Repertório, hinários digitalizados, cifras, slides e playbacks usados nos cultos.
Este índice foi montado a partir dos arquivos da pasta [`Musicas/`](Musicas) — todo
item da tabela aponta para o arquivo real no repositório.

> **Arquivo gerado — não edite à mão.** Para atualizar, ajuste as tabelas em
> [`tools/`](tools) e rode `python3 tools/build.py`, que reescreve este README.
> O script aborta se algum caminho não existir, então link quebrado não passa.

## Como o acervo está organizado

```
Musicas/
├── hinos/                 hinários da igreja
│   ├── hcc/               Hinário para o Culto Cristão (JUERP)
│   ├── cantor-cristao/    Cantor Cristão, completo e simplificado
│   └── harpa-crista/
├── canticos-maranata/     hinário Maranata / Vida Nova
│   ├── c-bom/
│   └── ibm-nh/            revisão usada pela igreja
├── contemporaneas/        cifrário A–W + repertório em uso
│   ├── A/ … W/
│   └── repertorio/        músicas ativas: cifra, slide e áudio
├── coral/                 partituras e ensaios por naipe
└── material-de-apoio/     escalas, dicionários de acordes, apostilas
```
